Что это такое

RuPy — это учебный слой поверх обычного Python. Мы не переписываем интерпретатор, а переводим русский синтаксис в стандартный Python-код и запускаем его через Python 3.11+.

Установка и запуск

  1. Установите пакет локально: python -m pip install -e .
  2. Запустите файл: rupy run путь/к/файлу.rupy
  3. Откройте REPL: rupy repl
