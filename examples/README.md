# Примеры RuPy

В этой папке собраны небольшие программы на `.rupy`, демонстрирующие русский синтаксис.

## Как запускать

```bash
rupy run examples/01_hello.rupy
rupy run examples/03_conditions.rupy
rupy run examples/10_files.rupy
```

Некоторые примеры используют файл `data.txt`, который лежит рядом.
