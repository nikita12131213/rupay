Ключевые слова

  • если → if
  • иначе → else
  • иначеесли → elif
  • для → for
  • пока → while
  • функция → def
  • класс → class
  • вернуть → return
  • прервать → break
  • продолжить → continue
  • попытаться → try
  • кроме → except
  • наконец → finally
  • поднять → raise
  • передать → pass
  • утверждать → assert
  • импорт → import
  • из → from
  • как → as
  • Истина → True
  • Ложь → False
  • Ничего → None

Встроенные функции и типы

  • печать → print
  • ввод → input
  • длина → len
  • диапазон → range
  • целое → int
  • число → float
  • строка → str
  • список → list
  • словарь → dict
  • множество → set
  • кортеж → tuple
  • открыть → open
