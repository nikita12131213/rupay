# RuPy — русский синтаксис поверх Python

RuPy — учебный проект, который добавляет русский синтаксис поверх обычного Python. Код на `.rupy` переводится в стандартный Python 3.11+ через `tokenize` и запускается без модификации интерпретатора.

## Что внутри проекта

- `ru_python/` — пакет с переводчиком и CLI `rupy`.
- `examples/` — набор небольших программ на `.rupy`.
- `tests/` — тесты переводчика и запуска.
- `site/` — статический обучающий сайт.

## Быстрый старт

1. Установите пакет локально:

```bash
python -m pip install -e .
```

2. Запустите файл:

```bash
rupy run examples/01_hello.rupy
```

3. Откройте REPL:

```bash
rupy repl
```

4. Выполните однострочный код:

```bash
rupy -c "печать(длина('RuPy'))"
```

## Примеры команд

```bash
rupy run examples/03_conditions.rupy
rupy run --show-python examples/04_for_range.rupy
```

## Как открыть сайт локально

```bash
cd site
python -m http.server 8000
```

После этого откройте браузер: `http://localhost:8000/index.html`.

## Как запустить тесты

```bash
python -m unittest discover -s tests
```

## Ограничения

- Переводятся только токены типа `NAME`, совпадающие со словарём. Строки и комментарии не затрагиваются.
- Нельзя использовать русские ключевые слова как имена переменных — они будут переведены.
- Поддерживаются только перечисленные ключевые слова и функции/типы.

## Как добавить новые ключевые слова

1. Откройте файл `ru_python/translator.py`.
2. Добавьте пару в словарь `KEYWORD_MAP`.
3. Запустите тесты и примеры, чтобы убедиться в корректности.
